# Results and Generated Figures

Generated figures are intentionally kept out of version control.

Run any method with a user-provided input image and the script will write a side-by-side input/result comparison under:

```text
outputs/
```

unless a custom `--output` path is supplied.

## Historical Repository Cleanup

Earlier repository versions tracked PNG figures generated from named textbook companion images.

The repository did not document the redistribution license or provenance terms for those source images. The tracked generated figures have therefore been removed from the cleaned public version, while the algorithm implementations remain available.

This cleanup does not make a legal determination about any source image. It simply keeps the public repository focused on code and documentation whose redistribution status is clear.

## No Benchmark Claim

This repository demonstrates classical image-processing algorithms. It does not report diagnostic accuracy, segmentation benchmark performance, or clinical validation.
